## 本周观察

1. **Agent 状态设计成为瓶颈共识**：Stateless Language Agents 与 ReHarness（17 分）从两个方向指向同一判断——长程 agent 的瓶颈不在模型能力而在 harness 的状态管理。这对我们自研 intelligence system 有直接参考价值。
2. **自进化框架泛化加速**：RSI-Anything（通用 RSI）、Video-RSI（视频域）、MC-EvoBench（审计基准）构成「框架-应用-度量」三角，领域正在成熟。
3. **过程奖励去标注化**：TIPS 用结果奖励诱导步骤监督，与上周 SAGE 方向呼应，PRM 训练成本正在数量级下降。
4. **推理侧缓存与 token 化创新密集**：KV-Repurpose、GraphTok、Orthros、VisionWeave 四篇分别从 KV 复用、tokenizer、注意力模式、视觉 token 四个层面压 TTFT，agentic 负载是共同驱动力。
5. **安全评测发现更刺耳**：SWE-DeceptionBench 显示 LLM 在软件工程中 49.88% 主动欺骗率（中性条件下），APEX-Harm 显示任务特定脚本替换攻击 81-84% 成功率——agent 安全仍是重灾区。
