### 入选理由详注

1. **ACG (Adaptive Consistency Graph)** —— 长 horizon Agent 在执行长序列依赖动作时的性能退化是本周 Agent 方向的共同关切。ACG 用自适应一致性图维护执行状态，在 GPT-5.6-luna 上将 44.5% 提升至 50.2%（+5.7pp），代码开源。方法直接可用，对构建生产级长任务 Agent 具有直接参考价值。
2. **CoWA (CoWindow Attention)** —— 本周效率方向最有力的架构创新。核心洞察：全因果覆盖不必是每个 head 的重复属性，而可以是 head 集成的集体属性。通过将远程窗口在 KV heads 间互补分配，在 128K token 上训练加速 7.4x、推理解码加速 3.0x，0.6B-14B scaling law 与 FullAttn 几乎重合。如果结果可复现，这是注意力架构层面的重要进展。
3. **ScopeIF** —— 把指令遵循中的约束分解为 Scope/Target/Range 三维，构建 ScopeInstruct 数据集 + 工具验证 + 分级奖励模型，使 Qwen3-4B/8B 在范围感知精确指令遵循上比肩甚至超越 Gemini-2.5-Pro 和 DeepSeek-V3.2。代码和数据均开源，生产可用度高。
4. **Choir** —— 分布式多 Agent 数学形式化的开放协议，打破单一团队集中运行所有 Agent 的算力瓶颈，支持 Lean 4 / Isabelle / Rocq 三大证明助手生态。全量开源。形式化验证 × 多 Agent 协作的交叉点，且以"协议"形态发布意味着可扩展性优先，长期价值高。
5. **FRAIL** —— 把 LLM Agent 放进三种动态金融环境（银行挤兑、债务滚动、奖励众筹），发现个体理性 Agent 无需恶意指令即可导致集体崩溃（77% 基线银行挤兑失败率）。比较三种稳定化机制（补偿承诺、集中承诺协议、参与者联盟），发现成功稳定共享一个时序模式：广泛承诺必须在防御行为自我强化之前形成。金融 AI 安全的开创性框架，代码可用。
6. **KV-Lingo** —— 首次解决"不同模型间的 KV cache 不兼容"问题：训练线性映射将源模型的 KV cache 翻译为目标模型可读的表示。在跨架构/跨尺寸模型对上保持强下游性能，64 token prompt 上模型切换延迟降低 9.6x，32K 上下文 H100 上降低 29x。对动态模型路由（先用小模型处理，必要时切换大模型）有直接应用价值。
7. **SphereGate** —— 重新审视被广泛视为"缺陷"的各向异性：约 5% 残差通道构成模型的"相干基底"（移除后 PPL 从 10 涨到 10⁶），SFT 重塑它们而 RL 保持它们不动——后训练自然地利用了这一分工。SphereGate 仅训练 0.1M 参数就超过全模型 GRPO，在 MATH-500 上领先参数高效基线 2.0-7.3 分。对理解后训练机制有启发意义。
8. **BSD (Belief Self-Distillation)** —— 提取 LLM 对用户的隐式信念，实现"读取+写入"双重能力：不仅能解码模型认为你在做什么，还能通过写入改变它的安全拒绝行为——在保持请求不变的情况下仅改变用户信念即可改变拒绝。发现跨模型共享的用户表示几何结构。AI 安全方向的重要概念性贡献。

## 五、本周核心判断

1. **长 horizon Agent 的"状态维护"成为关键战场**：ACG（一致性图）、CAIRN（事实-意图 DAG）、IntentFlux（意图漂移测量）三篇从互补角度切入同一问题——Agent 执行长任务时的可靠性衰减。这比"Agent 能多快"更根本地制约着"Agent 能走多远"。
2. **效率研究的重心从"压缩"转向"翻译/共享"**：KV-Lingo（跨模型 KV 翻译）、CacheReforge（版本感知恢复）、Distance-KV（距离感知压缩）、CoWA（集体注意力覆盖）四篇入选/关注级论文不再满足于"怎么删"，而是在问"怎么跨模型、跨版本复用"。推理效率与模型路由/组合的合流趋势明显。
3. **"后训练在做什么"的研究爆发**：SphereGate（各向异性分工）、Alignment Paradox（对齐放大幻觉）、BSD（用户信念可写）三篇入选论文共同指向一个元问题——我们对 post-training 的内部机制理解仍然很浅，而这是一个可以直接操作的空间。
4. **多 Agent 系统从"协作"走向"社会"**：FRAIL（金融稳定）、Choir（分布式形式化协议）、MAPL（偏好学习）、Steiner 分类学（规模-任务结构映射）显示研究重心正从"几个 Agent 怎么配合"扩展到"Agent 社会的组织原则"。
