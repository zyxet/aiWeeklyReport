## 三、本周关键洞察

### 1. Skills 生态完成了从"项目"到"行业"的跃迁

三个 Skills 项目合计 867K★。SKILL.md 仓库数量 6 个月内从 ~2,000 增长到 24,000+。这不是一个爆款项目的故事，是一个新图层诞生的故事。Stateless Language Agents 论文从学术侧回答了为什么这个图层有必要存在：**因为状态设计是 Agent 性能的真正瓶颈，而 Skills 是目前最好的状态管理实践**。

### 2. 自进化方向开始双线并行

工程侧（Ouroboros 直接自修改）和学术侧（RSI-Anything 世界模型驱动）同时推进。Ouroboros 的 1.5K★ 说明"自修改 Agent"仍然小众且争议巨大（CERT-FR 已介入），但 RSI-Anything 的 20 分说明学术界已经在为这条路打理论基础。关注两者在未来几个季度的合流。

### 3. 推理成本论文与开源商业模型互为因果

KV-Repurpose（缓存命中率 3.3%→63.9%）和 VisionWeave（省 43% token）不是孤立的学术成果——它们是 OpenCode Go $10/月两周收支平衡的技术地基。当学术界持续压低推理成本，开源 Agent 的商业模式空间就越大。这个飞轮正在加速。

### 4. 信息访问层的价值被低估

Agent-Reach 97K★ 说明开发者已经意识到 Agent 的信息管道是瓶颈，但 RATED 论文指出的"可用性感知"问题提醒我们：**能访问不等于可靠访问**。工具链的可靠性工程（动态反馈、故障切换、安全隔离）是下一个值得关注的子方向。
